## 怎么在本地看这个网页

直接双击 `index.html`，它会用你的默认浏览器打开。
不需要装任何东西，也不需要联网。

## 文件说明

| 文件 | 作用 | 会上传 GitHub 吗 |
| --- | --- | --- |
| `index.html` | 网站首页（当前只是占位页） | 会 |
| `research.md` | 需求研究：3 个类似产品的对比 + 本期不做什么 | 会 |
| `README.md` | 项目说明书，就是你现在看的这个文件 | 会 |
| `.gitignore` | 忽略名单，写明哪些文件不要上传 | 会 |
| `.env.example` | 环境变量模板，告诉大家需要配哪些项 | 会 |
| `.env` | 本地真实配置（含密码），只留在这台电脑上 | **不会**（已被忽略） |

## 关于 .env

`.env` 是存放数据库密码、密钥这类敏感信息的本地文件。
它已经被 `.gitignore` 忽略，永远不会出现在 GitHub 上。

需要新增配置项时，先写进 `.env.example`（这个是要上传的模板），
再在自己的 `.env` 里填上真实的值。
